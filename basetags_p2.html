Paragraph Tag, Quote Tags and Abbr tag

<p>This is a paragraph tag.</p> this is a blocking element used to define a paragraph of text. It is used to group related sentences together and create a visual separation between different sections of content on a webpage. The text inside the paragraph tag is displayed in a block format, with a line break before and after the paragraph.

<q>This is a quote tag.</q>Rajini kanth is the Super Star of Tamil Cinema. This is an inline element used to define a short quotation. It is used to indicate that the text inside the tag is a quote from another source, such as a book, article, or speech. The text inside the quote tag is typically displayed in quotation marks and may be styled differently from the surrounding text.

<abbr>This is an abbr tag.</abbr> This is an inline element used to define an abbreviation or acronym. HTML

Blockquote Tag

<blockquote>This is a blockquote tag. It is used to define a section of text that is quoted from another source. The text inside the blockquote tag is typically indented and may be styled differently from the surrounding text. Blockquotes are often used to highlight important quotes or to provide context for a particular topic.

Order List and Unordered List Tags

    <ol>This is an ordered list tag. It is used to define a list of items that are presented in a specific order. The items in an ordered list are typically numbered or lettered, and the order of the items is important. List of Groceries to buy:
  1. Milk
  2. Bread
  3. Eggs
    <ul>This is an unordered list tag. It is used to define a list of items that are presented in no particular order. The items in an unordered list are typically marked with bullet points or other symbols, and the order of the items is not important. List of Fruits to buy:
  • Apple
  • Banana
  • Orange
