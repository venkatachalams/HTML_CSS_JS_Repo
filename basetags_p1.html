HTML Basics

HTML stands for Hypertext Markup Language

HTML is used to create webpages and web applications

HTML consists of a series of elements that define the structure and content of a webpage

HTML elements are represented by tags, which are enclosed in angle brackets
HTML tags can be used to create headings, paragraphs, lists, links, images, and other types of content

Common Text format tags

<strong>This is a strong text.
<ins>This is an inserted text.
<del>This is a deleted text.
<em>This is an emphasized text.
<sup> tag is used represent super script text
Example: (a+b)2 = a 2 + b 2 +2ab
Here square values are respresented using super script
<sub> tag is used represent sub script text
Example: H2O is the chemiacal name for water Here 2 is respresented as subscript
<mark> Do not forget to buy milk today.

Self Closing Tags

<br> tag is used to create a line break in the text. It does not have a closing tag and is self-closing.
<hr> tag is used to create a horizontal line in the text. It does not have a closing tag and is self-closing.
<img> tag is used to display an image on the webpage. It does not have a closing tag and is self-closing. The 'src' attribute is used to specify the image source, and the 'alt' attribute is used to provide alternative text for the image.
<input> tag is used to create an input field for user input. It does not have a closing tag and is self-closing.

Image and Hyper link

<img> is used to embbed Images like this in HTML Page

<a> Tag is used to create a hyperlink to another webpage. The 'href' attribute is used to specify the URL of the linked page.
